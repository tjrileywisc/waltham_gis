
# Neighborhood character, taken seriously

What if we actually did take the character implied by zoning seriously? If a parcel is not meeting the minimum according to its zoning (the most common deficiency),
then that house is undesirable per the belief of some city councilors decades ago. We don't force the structure to be taken down, but we make it hard to make modifications
or rebuild on the same parcel without going through a Zoning Board of Appeals special permit process.

So let's go with that thought suggested by the wise councilors of yore, and knock down those homes. How many homes are gone? How many residents are gone?
If we merge adjacent lots together using some strategy, how many parcels are left, and how many people would fit into those homes?
